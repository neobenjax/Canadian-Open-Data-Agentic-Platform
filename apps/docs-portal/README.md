# CanData Documentation & Interactive Playground Portal
**App:** `docs-portal`  
**Stack:** Next.js 15 (App Router), Fumadocs, Tailwind CSS v4, TypeScript

## Features
- **Public Developer Docs:** Interactive guide for installing `candata-mcp` via `uv` / `pip` and connecting Claude Desktop, Cursor, and custom LangGraph agents.
- **Interactive API Sandbox:** Web-based query playground testing StatCan and Bank of Canada tools.
- **Dark-Mode Modern Design:** Zero-CLS, high-performance static rendering deployed to Vercel.
