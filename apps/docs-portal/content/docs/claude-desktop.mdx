# Client Configuration

CanData-MCP connects to any Model Context Protocol (MCP) compatible host application via standard input/output (`stdio`).

## Claude Desktop Configuration

Add the server to your `claude_desktop_config.json`:

- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
- **Linux:** `~/.config/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "candata": {
      "command": "uv",
      "args": [
        "run",
        "--directory",
        "/absolute/path/to/Canadian-Open-Data-Agentic-Platform",
        "candata-mcp"
      ],
      "env": {
        "PYTHONUNBUFFERED": "1"
      }
    }
  }
}
```

Restart Claude Desktop. You will see a hammer icon 🔨 indicating that `candata` tools (`search_statcan_cubes`, `get_cube_dimensions`, `get_series`, `execute_sql_analytics`) are active.

## Cursor IDE Configuration

1. Open Cursor Settings $\rightarrow$ **Features** $\rightarrow$ **MCP Servers**.
2. Click **Add New MCP Server**.
3. Fill in the details:
   - **Name:** `candata`
   - **Type:** `stdio`
   - **Command:** `uv run --directory /absolute/path/to/Canadian-Open-Data-Agentic-Platform candata-mcp`
4. Test the connection. Cursor Composer can now query official Statistics Canada cubes and Bank of Canada Valet rates directly from chat.
