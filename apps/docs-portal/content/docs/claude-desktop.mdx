# MCP Manual Registry & Client Setup

CanData-MCP connects to any Model Context Protocol (MCP) host application via standard input/output (`stdio`).

### Two Repositories: Distribution vs. Monorepo

- **Official Standalone MCP Server Repository:** [`Canadian-Open-Data-Agentic-Platform-MCP-Server`](https://github.com/neobenjax/Canadian-Open-Data-Agentic-Platform-MCP-Server)  
  *Use this repository for registering, testing, and running the standalone MCP server locally or in client applications.*
- **Platform Monorepo (Source of Truth):** [`Canadian-Open-Data-Agentic-Platform`](https://github.com/neobenjax/Canadian-Open-Data-Agentic-Platform)  
  *Houses the end-to-end multi-agent LangGraph orchestrator, DuckDB 1.2+ streaming engine, GTA housing benchmarks, DeepEval suites, and this documentation portal.*

---

## 1. Universal MCP JSON Configuration (Claude Desktop, Cursor, Windsurf, Zed)

Add the server to your client configuration file (e.g. `claude_desktop_config.json`, `.cursor/mcp.json`, or settings UI):

- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
- **Linux:** `~/.config/Claude/claude_desktop_config.json`

### Option A: Standalone Distribution via `uvx` (Recommended for All Users)

This executes directly from the standalone MCP distribution repository with zero local repository cloning required:

```json
{
  "mcpServers": {
    "candata": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://github.com/neobenjax/Canadian-Open-Data-Agentic-Platform-MCP-Server.git#subdirectory=packages/candata-mcp",
        "candata-mcp"
      ],
      "env": {
        "PYTHONUNBUFFERED": "1"
      }
    }
  }
}
```

### Option B: Local Standalone MCP Clone

If you cloned the standalone MCP Server distribution repository:

```json
{
  "mcpServers": {
    "candata": {
      "command": "uv",
      "args": [
        "run",
        "--directory",
        "/absolute/path/to/Canadian-Open-Data-Agentic-Platform-MCP-Server",
        "candata-mcp"
      ],
      "env": {
        "PYTHONUNBUFFERED": "1"
      }
    }
  }
}
```

### Option C: Monorepo Development

If you are developing inside the collaboration monorepo:

```json
{
  "mcpServers": {
    "candata": {
      "command": "uv",
      "args": [
        "run",
        "--directory",
        "/absolute/path/to/Canadian-Open-Data-Agentic-Platform",
        "python",
        "-m",
        "candata_mcp"
      ],
      "env": {
        "PYTHONPATH": "packages/candata-mcp/src",
        "PYTHONUNBUFFERED": "1"
      }
    }
  }
}
```

### Option D: Hardened Docker Container

If running with Docker without a local Python runtime:

```json
{
  "mcpServers": {
    "candata": {
      "command": "docker",
      "args": [
        "run",
        "-i",
        "--rm",
        "ghcr.io/neobenjax/canadian-open-data-agentic-platform/candata-mcp:latest"
      ]
    }
  }
}
```

Restart your client. You will see a hammer icon 🔨 or active tool status indicating that all `candata` tools (`search_statcan_cubes`, `query_statcan_vector`, `query_valet_series`, `execute_sql_analytics`, etc.) are registered and ready for queries.

## 2. Cursor IDE GUI Setup

1. Open Cursor Settings $\rightarrow$ **Features** $\rightarrow$ **MCP Servers**.
2. Click **Add New MCP Server**.
3. Fill in the details:
   - **Name:** `candata`
   - **Type:** `stdio`
   - **Command:** `uvx --from git+https://github.com/neobenjax/Canadian-Open-Data-Agentic-Platform-MCP-Server.git#subdirectory=packages/candata-mcp candata-mcp`
4. Test the connection. Cursor Composer can now query official Statistics Canada cubes, Bank of Canada Valet rates, and Open Government datasets directly from chat.
