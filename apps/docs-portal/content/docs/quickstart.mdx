# Quickstart & Installation

CanData-MCP is packaged with zero unnecessary runtime dependencies and runs anywhere with Python 3.12+.

## 1. Standalone Distribution via `uvx` (Recommended)

You can launch and connect to the official FastMCP stdio server in a single command using Astral `uvx`:

```bash
uvx --from "git+https://github.com/neobenjax/Canadian-Open-Data-Agentic-Platform-MCP-Server.git#subdirectory=packages/candata-mcp" candata-mcp
```

## 2. Monorepo Development Installation

If you are developing inside a clone of the monorepo:

```bash
# Clone the repository
git clone https://github.com/neobenjax/Canadian-Open-Data-Agentic-Platform.git
cd Canadian-Open-Data-Agentic-Platform

# Synchronize virtual environment packages
uv sync

# Run unified pre-flight verification
uv run python scripts/verify.py

# Launch the FastMCP stdio server locally
# Linux / macOS:
PYTHONPATH=packages/candata-mcp/src uv run python -m candata_mcp

# Windows (PowerShell):
$env:PYTHONPATH="packages/candata-mcp/src"; uv run python -m candata_mcp
```

## 3. Running with Docker Container

If you prefer running without a local Python environment:

```bash
docker run -i --rm ghcr.io/neobenjax/canadian-open-data-agentic-platform/candata-mcp:latest
```

## 4. Running the Multi-Agent Streamlit UI

To explore the multi-agent execution pipeline in real-time with unit-aware Plotly charts:

```bash
uv sync --extra ui --extra agent
uv run streamlit run apps/agent-ui/app.py
```
