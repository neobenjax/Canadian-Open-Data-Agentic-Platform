# Kickoff Onboarding Workflow Test Sandbox (`CAN-00`)

This document is dedicated to testing and verifying the repository workflow during the kickoff onboarding meeting and for team members practicing their Gitflow and Linear synchronization cycle.

---

## 🧪 Purpose
- Allows live testing of:
  1. Transitioning a task to `IN PROGRESS` in Linear & `TASKS.md`
  2. Branch creation: `feat/CAN-00-test-workflow-sandbox`
  3. Conventional commit with Linear issue key: `[CAN-00] test: practice gitflow and linear state synchronization`
  4. Pushing feature branch to `origin`
  5. Transitioning task to `IN REVIEW` in Linear & `TASKS.md`
  6. PR creation with `Closes CAN-00`
  7. Triangular review assignment and approval
  8. Squash merge to `main`
  9. Transitioning task to `DONE` in Linear & `TASKS.md`
  10. Feature branch purging locally and remotely
