The Problem in Plain English

Why ChatGPT & Claude Guess on Canadian Data

If you ask an AI model about Canadian rent, inflation, or housing, it either makes up a number or throws an error. Here's why:

THE GUESSWORK

Models Confidently Invent Numbers

Ask Claude about Brampton's rent growth vs inflation. It will confidently tell you 18.2% because it mixes up 2-bedroom turnover rents with total census averages.

❌ Claude Guess: 18.2% rent hike
✅ StatCan Fact: 8.4% official average
THE FILE SIZE PROBLEM

Canadian Tables are 200MB Beasts

Statistics Canada tables are huge CSVs. You can't just feed a 200MB file into an AI prompt—it costs $12 per question and crashes the chat.

⚡ What we do: DuckDB slices 200MB down to a clean 2KB summary in 1.4 seconds.

The Technology

The Tech Stack: How It Actually Works

We keep it fast, simple, and reliable using four key pieces:

HOW DATA FLOWS
1. Official Canadian APIs: Simple async web requests fetching official data from StatCan, Bank of Canada, and OpenGov.
2. DuckDB (The Slicer): An ultra-fast in-memory database that filters 200MB tables down to tiny 2KB summaries in 1.4 seconds.
3. FastMCP 2.0 (The Bridge): Connects our data tools directly to Claude Desktop, Cursor, and custom agents.
4. LangGraph (The Brain): Coordinates specialized sub-agents (analyst, verifier) so the AI never guesses or makes math mistakes.
WHERE FILES LIVE (CLEAN REPO)
/packages: Public tools anyone can install via pip (`candata-mcp` and `agent-orchestrator`).
/apps: Public documentation website and interactive demo playground.
/collaboration: Our private team hub (meeting notes, benchmark scorecards, LinkedIn post drafts).
